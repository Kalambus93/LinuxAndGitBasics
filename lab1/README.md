# Задание №1

## 1.1 — Подсчёт слов в файле

```bash
wc -w dictionary_2026.txt
```

- `-w` → считает **слова** (разделённые пробельными символами), а не строки или байты.

---

## 1.2 — Поиск слов с двумя `c`, разделённых символами

```bash
grep -icE '\b\w*[c]\w*[c]\w*\b' dictionary_2026.txt
```

| Флаг | Значение                                         |
| ---- | ------------------------------------------------ |
| `-i` | без учёта регистра                               |
| `-c` | вывести только **количество** совпадений (строк) |
| `-E` | расширенные регулярные выражения                 |

>[!important]
> Разбор
> - `\b` — граница слова (начало/конец)
> - `\w*` — ноль или более буквенно-цифровых символов
> - `[c]` — первая буква `c`
> - `\w` — **ровно один** любой символ внутри слова
> - `[c]` — вторая буква `c`
> - `\w*` — ноль или более символов до конца слова

---

## 1.3 — Слова ровно с двумя `t`, разделённые хотя бы одним символом

```bash
grep -icE '\b[^t]*t[^t]+t[^t]*\b' dictionary_2026.txt
```

>[!important]
> Разбор
> - `\b` — граница слова
> - `[^t\W]*` — ноль или более **символов слова** (букв/цифр), но не `t`
> - `t` — **первая** `t`
> - `[^t\W]+` — минимум один символ слова, но не `t` (гарантирует, что `t` не идут подряд)
> - `t` — **вторая** `t`
> - `[^t\W]` — ровно один символ слова, но не `t`, перед концом слова
> - `\b` — граница слова (конец)

---

## 1.4 — Топ-4 префикса (без "oo"), по алфавиту

```bash
grep -v 'oo' dictionary_2026.txt | cut -c1-3 | sort | uniq -c | sort -rn | head -n 4 | sort | awk '{print $2}'
```

>[!tip]
> Пайплайн по шагам
> 1. `grep -v 'oo'` — отфильтровать строки, **содержащие** `oo` (оставить только без `oo`)
> 2. `cut -c1-3` — извлечь первые 3 символа (префикс)
> 3. `sort` → `uniq -c` — сгруппировать и подсчитать частоту каждого префикса
> 4. `sort -rn` — отсортировать по числовому значению счётчика (по убыванию)
> 5. `head -n 4` — оставить только топ-4 самых частых
> 6. `sort` — повторно отсортировать эти 4 строки в **алфавитном** порядке
> 7. `awk '{print $2}'` — вывести только второй столбец (сам текст префикса), отбросив число-счётчик

# Задание №2

## Разбор ключевых решений

| Подзадача                       | Ключевая команда                                          | Почему это правильно                                                                                                                                                                                                 |
| ------------------------------- | --------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **0. Пустая директория**        | `rm -rf "$DIR" && mkdir -p "$DIR"`                        | `rm -rf` удаляет старую папку со всем содержимым, `mkdir -p` создает новую. Это единственное решение, гарантирующее _пустоту_ директории.                                                                            |
| **1. Число в последней строке** | `wc -l < file >> file`                                    | Оператор `<` передаёт файл на ввод, поэтому `wc` выводит **только число** (без имени файла). `>>` дописывает его в конец.                                                                                            |
| **2. Фильтр 6 < X < 10**        | `awk '$1 > 6 && $1 < 10 { $1=""; sub(/^ /, ""); print }'` | `$1` — это счётчик от `uniq -c`. Мы обнуляем его (`$1=""`), удаляем оставшийся ведущий пробел (`sub`) и печатаем остаток строки. Это **безопасно работает с темами из нескольких слов** (в отличие от `{print $2}`). |
| **3. Пересечение тем**          | `grep "A" \| grep "B" \| grep "C"`                        | Последовательная фильтрация оставляет только те строки CSV, которые содержат все три подстроки одновременно.                                                                                                         |
| **4. Сортировка по фамилии**    | `sort -k2,2 -k1,1`                                        | Поскольку в задании указано, что _"фамилии записаны в качестве одного слова"_, а формат обычно "Имя Фамилия", `-k2,2` сортирует по второму слову (фамилии), а `-k1,1` разрешает совпадения по имени.                 |

>[!warning]
> Важная проверка перед запуском
> 1. Сделайте скрипт исполняемым: `chmod +x script.sh`
> 2. Запустите: `./script.sh`

## Используемые утилиты (шпаргалка)

| Утилита | Назначение |
|---------|------------|
| `wc` | подсчёт строк, слов, байтов |
| `grep` | поиск по регулярным выражениям |
| `cut` | извлечение колонок/символов |
| `sort` | сортировка строк |
| `uniq` | удаление/подсчёт дубликатов |
| `awk` | мощный язык обработки текста |
| `sed` | потоковый редактор |
| `head` / `tail` | вывод первых/последних строк |
